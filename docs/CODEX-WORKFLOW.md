# Codex Workflow

1. Sempre ler README, docs/ROADMAP.md, PRD e ADRs relevantes antes de editar.
2. Verificar `git status` antes e depois.
3. Trabalhar apenas no ciclo solicitado.
4. Nao implementar funcionalidades futuras por antecipacao.
5. Preservar isolamento multi-tenant e autorizacao server-side.
6. Criar/atualizar testes junto com cada regra.
7. Atualizar documentacao/ADR quando uma decisao arquitetural mudar.
8. Em novas interfaces, reutilizar o Meca Dojo Design System em `docs/ux/design-system.md` e os componentes base de `apps/web/src/components/ui`.
9. Ao finalizar: resumir arquivos alterados, decisoes, testes executados, pendencias e riscos.
