# Codex Workflow
1. Sempre ler README, docs/ROADMAP.md, PRD e ADRs relevantes antes de editar.
2. Verificar `git status` antes e depois.
3. Trabalhar apenas no ciclo solicitado.
4. Não implementar funcionalidades futuras por antecipação.
5. Preservar isolamento multi-tenant e autorização server-side.
6. Criar/atualizar testes junto com cada regra.
7. Atualizar documentação/ADR quando uma decisão arquitetural mudar.
8. Ao finalizar: resumir arquivos alterados, decisões, testes executados, pendências e riscos.
