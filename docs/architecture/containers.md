# C4 - Containers

- Web/PWA: Next.js, React, TypeScript, App Router e Tailwind CSS.
- API: Spring Boot 3, Java 21, Maven, Spring Data JPA, Flyway, Bean Validation, Actuator e OpenAPI.
- Database: PostgreSQL.
- Cache local: Redis disponivel na infraestrutura para ciclos futuros.
- Object storage local: MinIO disponivel na infraestrutura para ciclos futuros.

No Cycle 00, Redis e MinIO sao provisionados pelo Docker Compose, mas ainda nao sao usados pela aplicacao.
