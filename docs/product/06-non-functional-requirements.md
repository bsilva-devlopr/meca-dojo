# Requisitos Não Funcionais
- Mobile-first e acessível.
- API versionada em /api/v1.
- PostgreSQL + migrations Flyway.
- Isolamento de tenant em toda entidade de negócio aplicável.
- Senhas nunca armazenadas em texto puro.
- Autorização server-side.
- Auditoria para alterações críticas.
- Datas persistidas de forma consistente e exibidas no timezone da unidade.
- Testes automatizados para regras críticas.
